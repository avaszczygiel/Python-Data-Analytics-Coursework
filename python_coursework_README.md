# Python Data Analytics and Text Mining Coursework

**Course:** AA640 - Data Analytics and Text Mining
**Institution:** Bryant University
**Tools:** Python, Pandas, Matplotlib, Seaborn, NLTK, scikit-learn, Gensim

---

## Overview

This repository contains my weekly activity notebooks from AA640, a graduate-level course covering the full data analytics pipeline in Python. The notebooks progress from core Python fundamentals through advanced natural language processing techniques, reflecting hands-on work completed across the semester.

---

## Notebook Progression

| # | Notebook | Topics Covered |
|---|---|---|
| 01 | [Python Basics and Data Types](notebooks/01_python_basics_data_types.ipynb) | Objects, numeric types, booleans, strings, f-strings, lists, tuples, dictionaries, indexing and slicing |
| 02 | [Logic and Control Flow](notebooks/02_logic_and_control_flow.ipynb) | Comparison and boolean operators, built-in functions, if/elif/else, for loops, while loops |
| 03 | [Functions, Files, and Pandas](notebooks/03_functions_files_pandas.ipynb) | Writing functions, parameters and return values, reading files, Pandas Series and DataFrames, .loc[] and .iloc[], boolean indexing |
| 04 | [Aggregation and Data Cleaning](notebooks/04_aggregation_data_cleaning.ipynb) | GroupBy, .agg(), pivot tables, handling missing values, removing duplicates, outlier detection |
| 05 | [Data Visualization](notebooks/05_data_visualization.ipynb) | Matplotlib (line, bar, scatter, histogram), Seaborn, combining plots, building multi-panel dashboards |
| 06 | [Text as Data](notebooks/06_text_as_data.ipynb) | Regex patterns, tokenization, text preprocessing pipelines, web scraping |
| 07 | [Text Vectorization](notebooks/07_text_vectorization.ipynb) | Bag of words, TF-IDF, n-grams, bigram analysis, word clouds, applied to presidential debate transcripts |
| 08 | [Sentiment Analysis](notebooks/08_sentiment_analysis.ipynb) | Lexicon-based scoring, VADER, NRC emotion analysis, candidate-level sentiment comparison |
| 09 | [Topic Modeling](notebooks/09_topic_modeling.ipynb) | LDA (Latent Dirichlet Allocation), model tuning, topic interpretation, newspaper article analysis |
| 10 | [Word Embeddings](notebooks/10_word_embeddings.ipynb) | Word2Vec, document vectors, semantic similarity, t-SNE visualization |

## Skills Demonstrated

**Core Python**
- Data structures (lists, tuples, dictionaries), control flow, functions, file I/O

**Data Analysis**
- Pandas for data manipulation, aggregation, and cleaning
- Handling missing values, duplicates, and outliers

**Data Visualization**
- Matplotlib and Seaborn for exploratory and presentation-ready charts
- Multi-panel dashboard layouts

**Natural Language Processing**
- Text preprocessing and cleaning pipelines
- Regex, tokenization, stopword removal
- TF-IDF vectorization and n-gram analysis
- Sentiment scoring with VADER and NRC lexicons
- Topic modeling with LDA
- Word embeddings with Word2Vec and t-SNE visualization

## How to Run

1. Clone this repository
2. Install dependencies: `pip install pandas matplotlib seaborn nltk scikit-learn gensim wordcloud`
3. Open any notebook in Jupyter or Google Colab
4. Run cells in order from top to bottom
